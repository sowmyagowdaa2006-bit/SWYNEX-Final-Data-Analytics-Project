# SWYNEX Data Analyst Internship – Final Data Analytics Project

## Project Overview

This project combines the work completed during my SWYNEX Data Analyst Internship into one complete data analytics case study.

The project covers data cleaning, exploratory data analysis, visualization and dashboard development using a financial Budget vs Actual dataset.

## Problem Statement

The objective of this project is to clean and analyze financial data to understand budget and actual spending patterns, identify trends and differences, and present the findings through an interactive dashboard.

## Dataset Information

The dataset contains financial transaction information including:

- Transaction ID
- Date
- Department
- Category
- Region
- Budget Amount
- Actual Amount

The dataset was used to analyze financial performance across departments, categories and months.

## Data Cleaning

The raw dataset was investigated for common data-quality issues.

The following steps were performed:

- Identified missing values
- Identified duplicate records
- Removed 10 duplicate records
- Replaced unresolved missing values with "Unknown"
- Standardized the date format
- Documented the identified issues in a Data Audit sheet
- Prepared a cleaned dataset for analysis

## Exploratory Data Analysis

The cleaned dataset was analyzed using Microsoft Excel.

The analysis included:

- Total, average, minimum and maximum values
- Department-level analysis
- Category-level analysis
- Monthly trend analysis
- Budget vs Actual comparison
- Identification of high and low values
- PivotTables and PivotCharts

## Dashboard

An interactive dashboard was created using Microsoft Power BI.

The dashboard includes:

- Total Actual Amount KPI
- Total Budget Amount KPI
- Average Actual Amount KPI
- Maximum Actual Amount KPI
- Actual Amount by Department
- Actual Amount by Category
- Monthly Actual Amount Trend
- Budget vs Actual by Department
- Interactive filters for Department, Category, Region and Payment Method

## Key Business Insights

- HR recorded the highest total Actual Amount among departments.
- Utilities recorded the highest total Actual Amount among categories.
- July recorded the highest monthly Actual Amount.
- Marketing had the largest positive difference between Actual Amount and Budget Amount.
- Actual Amount ranged from 8,002 to 169,973.
